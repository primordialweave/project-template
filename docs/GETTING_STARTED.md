# Getting Started

This file belongs to a starter template; it contains **no real product installation instructions**.

## Contributors

1. Clone the repository.
2. Read [Project Setup](../PROJECT-SETUP.md).
3. Run the built-in template checks:

```bash
python3 scripts/check_project.py
python3 -m unittest discover -s tests -v
```

## After the project is initialized

Document tested system requirements, dependencies, supported platform versions, build commands, test commands, troubleshooting and how to obtain a release. Avoid copying commands that do not work on the project's target platforms.

macOS projects should state their minimum macOS, Swift and Xcode versions as appropriate.
