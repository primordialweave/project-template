# Brand Integration

A project belongs to the [Primordial Weave](https://github.com/primordialweave) ecosystem, but should have its **own** product name and clearly identifiable icon.

- Use low-saturation ink, warm paper, and restrained cinnabar as visual family cues.
- Do not duplicate the organization's Taiji logo across unrelated products.
- Avoid unverified historical claims and fabricated seal-script glyphs.
- Use approved organization PNG assets from the maintained brand repository; do not stretch preview images into production graphics.

- Logos, fonts, seals and illustrations require a **separate rights decision** from the project's code license.

Do not redistribute font files in the repository without appropriate permission.
