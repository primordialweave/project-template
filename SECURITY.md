# Security Policy

**Do not disclose exploit details or private information in public issues.**

1. Visit this repository's **Security** tab and use **Report a vulnerability** if private reporting is enabled.
2. If unavailable, open a non-sensitive issue asking maintainers to establish a private contact route.
3. Submit affected versions, reproduction steps and impact only via the resulting private channel.

Maintainers should document supported versions, realistic response expectations and any published security notices. Never commit credentials, signing keys or personal data. Rotate compromised secrets.

See the [organization default](https://github.com/primordialweave/.github/blob/main/SECURITY.md).
