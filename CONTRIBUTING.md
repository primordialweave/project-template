# Contributing

Thank you for considering a contribution.

1. Read [Project Setup](PROJECT-SETUP.md) and [Code of Conduct](CODE_OF_CONDUCT.md).
2. Open an issue for significant features or breaking changes before writing code.
3. Follow the actual project's toolchain and CI commands after project setup.
4. Make focused PRs with a reason for the change and validation notes.
5. Redact sensitive content from logs/screenshots and ensure you have rights to contributed artwork.

For this **starter template**, validate with `python3 scripts/check_project.py` and `python3 -m unittest discover -s tests -v`. Replace these with project-specific build and test commands before a release.

Individual repositories may have additional contribution requirements. A code license must be selected before a project claims an open-source release.
